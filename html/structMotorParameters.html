Detailed Description

Complete set of electrical, mechanical, and thermal parameters for one motor.

All resistance and inductance values are single-phase quantities (not phase-to-phase). The controller's internal RL model uses these directly:

\[ V = R \cdot I + L \cdot \frac{dI}{dt} + V_{\text{BEMF}} \]

Thermal parameters

The four thermal fields parameterise the two-node thermal model in TwoNodeThermalModel (winding → case → ambient):

Field Symbol Typical range Notes
R_th_winding_case \(R_{wc}\) 0.5 – 5 °C/W From datasheet or thermal measurement
C_th_winding \(C_w\) 5 – 50 J/°C Winding thermal mass
R_th_case_ambient \(R_{ca}\) 1 – 20 °C/W Depends heavily on mounting / airflow
C_th_case \(C_c\) 50 – 500 J/°C Housing/heatsink thermal mass

Default values of 0 and 1 are intentional no-ops that produce an unbounded temperature rise — replace them with real values before enabling BrushlessController::enable_thermal_limiting().

Note
R_th_winding_case and C_th_winding are the most critical parameters for protecting against fast I²R transients. R_th_case_ambient and C_th_case govern long-term steady-state temperature.
