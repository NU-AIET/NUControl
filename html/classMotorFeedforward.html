Detailed Description

Bilinear (Tustin) inversion of the first-order RL motor model for feedforward.

Models the per-phase motor winding as a series RL circuit:

\[ V(s) = (R + sL)\, I(s) \]

The bilinear-transform inversion yields the discrete-time voltage predictor:

\[ V[n] = \underbrace{\!\left(\frac{2L}{T}+R\right)\!}_{A}\! I[n] + \underbrace{\!\left(-\frac{2L}{T}+R\right)\!}_{B}\! I[n-1] - V[n-1] \]

This is used in BrushlessController::feedforward() (inline implementation) to pre-compute the voltage required to achieve a desired current trajectory.

Note
This class is defined for documentation completeness. The controller uses an inline implementation of the same formula rather than instantiating MotorFeedforward as a filter object, because the phase-current and phase-voltage states are managed by the controller's own member variables.
