Detailed Description

Temperature sensor abstraction and two-node winding thermal model for motor current derating.

Four components are provided:

<tt>TemperatureSensor</tt> (abstract)

Virtual base class with a single read_celsius() method. Concrete subclasses can represent NTC thermistors, I²C/SPI digital sensors, or any other measurement source. The thermal model holds a raw pointer to this base, so lifetime management is the caller's responsibility.

<tt>NTCThermistor</tt>

Reads an NTC thermistor wired as a voltage divider on an Arduino analog pin (R_series pull-up from V_supply to ADC pin, NTC from ADC pin to GND). Uses the B-value (beta-coefficient) equation:

\[ T = \frac{1}{\frac{\ln(R/R_0)}{B} + \frac{1}{T_0}} \quad [\text{K}] \]

The conversion is done in refresh() (blocking, call from the main loop); read_celsius() returns the cached result and is ISR-safe.

<tt>DMANTCThermistor</tt>

Identical B-value conversion but reads from a volatile uint16_t buffer that is kept current by a background DMA transfer configured via adc_dma_hal.hpp. read_celsius() is fully ISR-safe and non-blocking; no refresh() call is needed. This is the preferred implementation when a thermistor is mounted in a thermally active location (e.g., on the motor windings) where updates at the full control rate are desirable.

Difference equations (forward Euler, safe at control-loop rates):

\[ \dot{T}_w = \frac{P - (T_w - T_c)/R_{wc}}{C_{w}} \]

\[ \dot{T}_c = \frac{(T_w - T_c)/R_{wc} - (T_c - T_{amb})/R_{ca}}{C_{c}} \]

Optional physical sensors for winding and case nodes: A TemperatureSensor can be attached to either or both nodes via set_winding_sensor() / set_case_sensor(). When a sensor is present, its reading replaces the ODE prediction for that node each tick — the sensor measurement is treated as ground truth. Nodes without a sensor continue to be driven by the ODE, using the best available (potentially sensed) estimate of adjacent nodes for heat-flow calculations.

Current derating begins when \( T_w \) reaches 75 % of the thermal headroom above ambient (configurable), and scales linearly to zero at \( T_{max} \):

\[ I_{limit} = I_{max} \cdot \frac{T_{max} - T_w}{T_{max} - T_{warn}} \quad \text{for } T_w \in [T_{warn},\, T_{max}] \]

Note
The thermal model runs at the control-loop rate (typically 10 kHz). Forward Euler is stable when the control period is much shorter than the smallest thermal time constant ( \( R_{wc} \cdot C_w \)). For motor windings this is typically several seconds, so 100 µs steps are well within the stability margin.
All TemperatureSensor pointers held by TwoNodeThermalModel are non-owning; the sensor objects must outlive the model. All sensors passed to the model must return from read_celsius() without blocking — use DMANTCThermistor or the NTCThermistor cache pattern.
