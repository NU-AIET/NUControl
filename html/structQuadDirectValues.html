Detailed Description

template<typename T>
struct QuadDirectValues< T >

Rotating dq (quadrature–direct) coordinate frame values.

The dq frame rotates synchronously with the rotor flux vector at electrical angle \( \theta_e \). In steady state, all quantities become DC, enabling simple PI current control:

  • q (quadrature): torque-producing component \( I_q \); controls \( \tau = k_T I_q \).
  • d (direct): flux-producing component \( I_d \); held at zero for maximum torque per ampere (MTPA) with surface-mounted magnets.

The scalar constructor enables use as a DiscreteFilter state type.
