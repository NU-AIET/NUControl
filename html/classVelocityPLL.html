Detailed Description

2nd-order phase-locked loop for simultaneous position and velocity estimation.

Tracks encoder angle with a recursive state observer. The PLL drives a position estimate toward the measured angle using a proportional-integral loop, and its integral state is the velocity estimate:

\[ e[n] = \theta_\text{meas}[n] - \hat\theta[n-1] \]

\[ \hat\theta[n] = \hat\theta[n-1] + (\hat\omega[n-1] + K_p\,e[n])\,T_s \]

\[ \hat\omega[n] = \hat\omega[n-1] + K_i\,e[n]\,T_s \]

Gains are derived from the desired closed-loop natural frequency and damping:

\[ K_p = 2\zeta\omega_n, \quad K_i = \omega_n^2 \]

For ζ = 1/√2 (Butterworth), the −3 dB velocity bandwidth equals bandwidth_hz.

Note
Uses Forward Euler integration. Stable for bandwidth_hz ≪ sampling_hz / (2π). At 10 kHz sampling, bandwidths up to ~500 Hz are well-behaved.
