Detailed Description

Identifies a single FlexPWM output pin by its peripheral location.

Stores a pointer to the FlexPWM module base address, the submodule index (0–3), and the output channel within that submodule (A=0, B=1). A null module pointer indicates an invalid or unrecognized pin.

Note
On iMXRT1062, each FlexPWM module has 4 submodules, each with two complementary outputs (A and B). The A channel uses VAL2/VAL3 compare registers; the B channel uses VAL4/VAL5.
