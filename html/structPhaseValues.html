Detailed Description

template<typename T>
struct PhaseValues< T >

Three-phase (abc) coordinate frame values.

Holds per-phase quantities such as currents [A] or voltages [V] in the stationary abc frame. The scalar constructor initialises all three phases to the same value, enabling use as the fill type for DiscreteFilter<PhaseValues<T>, float>.
