Detailed Description

template<typename T>
class Butterworth2nd< T >

2nd-order Butterworth low-pass filter discretised via bilinear transform.

Uses frequency pre-warping to place the −3 dB cutoff exactly at cutoff_hz in the discrete-time frequency domain:

\[ \alpha = \frac{1}{\tan(\pi f_c / f_s)} \]

\[ \beta = \alpha^2 + \sqrt{2}\,\alpha + 1 \]

Numerator (b) coefficients (amplitude-normalised):

\[ b_0 = b_2 = \frac{1}{\beta}, \quad b_1 = \frac{2}{\beta} \]

Denominator (a) feedback coefficients:

\[ a_0 = \frac{-2\alpha^2 + 2}{\beta}, \quad a_1 = \frac{\alpha^2 - \sqrt{2}\,\alpha + 1}{\beta} \]

Template Parameters
TSignal type (typically float).
Note
The α pre-warp factor is the reciprocal of the Butterworth design parameter commonly denoted Ω_c in textbooks; α = cot(π f_c / f_s).
