Detailed Description

Coordinate-frame structs and Clarke/Park transform functions for FOC.

Defines the three coordinate frames used in field-oriented control:

Frame Type Axes
Phase (abc) PhaseValues<T> a, b, c
Stationary AlphaBetaValues<T> α, β
Rotating QuadDirectValues<T> q (torque), d (flux)

Clarke Transform (abc → αβ)

Amplitude-invariant form (assumes I_a + I_b + I_c = 0, so I_c is not needed):

\[ \alpha = I_a, \qquad \beta = \frac{1}{\sqrt{3}}\,I_a + \frac{2}{\sqrt{3}}\,I_b \]

Park Transform (αβ → dq)

Sign convention in this implementation:

\[ q = -\sin\theta\,\alpha + \cos\theta\,\beta, \qquad d = \cos\theta\,\alpha + \sin\theta\,\beta \]

where \( \theta \) is the electrical angle in radians.

Note
Both the forward and inverse transforms are implemented as free template functions so they work for any numeric type T that supports the required arithmetic operators.

Inverse Clarke transform: αβ → abc.

Reconstructs the three-phase frame from the stationary αβ frame:

\[ I_a = \alpha, \qquad I_b = -\tfrac{1}{2}\alpha + \tfrac{\sqrt{3}}{2}\beta, \qquad I_c = -\tfrac{1}{2}\alpha - \tfrac{\sqrt{3}}{2}\beta \]

Forward Park transform: αβ → dq.

Rotates the stationary αβ frame into the rotor-synchronous dq frame using electrical angle \( \theta \):

\[ q = -\sin\theta\,\alpha + \cos\theta\,\beta, \qquad d = \cos\theta\,\alpha + \sin\theta\,\beta \]

Note
The q-axis leads the d-axis by 90° in this convention, which places the q-axis in the direction of maximum torque production for a rotor with d-axis aligned to the flux axis.

◆ phases_to_alphabeta()

template<typename T >
AlphaBetaValues< T > phases_to_alphabeta ( PhaseValues< T >  phases)

Forward Clarke transform: abc → αβ (amplitude-invariant).

Projects the three-phase abc frame onto the orthogonal αβ frame. Uses the KCL constraint \( I_a + I_b + I_c = 0 \) so that only two measurements are required:

\[ \alpha = I_a, \qquad \beta = \frac{1}{\sqrt{3}}\,I_a + \frac{2}{\sqrt{3}}\,I_b \]

Constants _1__SQRT_3_ and _2__SQRT_3_ are defined in helpers.hpp.

Inverse Park transform: dq → αβ.

Rotates the dq frame back to the stationary αβ frame:

\[ \alpha = \cos\theta\,d - \sin\theta\,q, \qquad \beta = \sin\theta\,d + \cos\theta\,q \]
