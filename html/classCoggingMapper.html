Detailed Description

template<std::size_t steps_>
class CoggingMapper< steps_ >

Automated cogging-torque and phase-voltage mapping sweep.

Drives a BrushlessController through steps_ angular set-points within a configurable range, records steady-state torque and phase voltages at each point, and reports results over Serial for import into AnticoggingCompensator.

Template Parameters
steps_Number of measurement points per direction per loop. Uniformly distributed over the configured range. Typical: 200–1000.

Starts the cogging-map sweep.

Initialises the sweep state, optionally disables existing anticogging compensation (so only raw cogging is captured), starts the controller, and launches the TeensyTimerTool timer at 100 µs.

The sweep runs autonomously via the timer callback. Blocking I/O (Serial output) only occurs at the end of each loop in report_out().

Parameters
loopsNumber of sweeps per direction (CW and CCW). Results from all loops are reported; the caller should average them offline.
disable_coggingIf true (default), calls controller_.disable_anticog() before starting so that the map captures raw cogging without feedforward interference.
Warning
Calling map_cogging() starts an autonomous control loop. Any concurrent use of the same BrushlessController will corrupt the sweep.

Overrides the default PD+I position-controller gains.

Default gains are tuned for the T-Motor U2535. Adjust for different motors by starting with kp ≈ 0.5–2× the plant gain and kd ≈ 0.05–0.2× kp. High ki can cause overshoot and missed targets.

Parameters
kpProportional gain [Nm/rad].
kiIntegral gain [Nm/(rad·s)].
kdDerivative gain [Nm·s/rad] (acts on velocity).
intl_maxIntegral clamp magnitude [Nm] (anti-windup).

Restricts the sweep to a sub-arc of the full revolution.

Must be called before map_cogging(). Targets are distributed uniformly within the range. CW pass covers [start, end); CCW pass covers (start, end]. Default is [0, 2π) — a full revolution.

Parameters
startRange start angle [rad]. Precondition: 0 ≤ start < end.
endRange end angle [rad]. Precondition: start < end ≤ 2π.

Sets the number of ticks to wait after first lock before accumulating.

After the shaft enters the tolerance band, the mapper waits steps control ticks (at 100 µs each) for PD+I ring-down transients to decay before sampling torque and voltage. Default: 200 (= 20 ms). Set to 0 to accumulate immediately on first entry (original behaviour).

Parameters
stepsNumber of 100 µs ticks to wait after first lock.

Configures the per-target timeout behaviour.

If state is true, a target that is not reached within timeout_max control ticks is marked with timeout_val and the sweep moves on. This prevents a stalled motor from blocking the entire map.

Parameters
statetrue to enable timeout (default), false to wait forever.
timeout_maxNumber of 100 µs ticks before timeout (default: 200000 = 20 s).
timeout_valSentinel value written to torques_ and phase_volts_ on timeout (default: −127.0). Easily identified in post-processing.
