Detailed Description

template<typename T>
class PIController< T >

Discrete-time PI controller using the Tustin (trapezoidal) method.

The continuous-time PI transfer function \( C(s) = K_p + K_i/s \) is discretised using the bilinear substitution \( s = \tfrac{2}{T}\tfrac{z-1}{z+1} \), yielding the difference equation:

\[ u[n] = \underbrace{(K_p + \tfrac{K_i T}{2})}_{b_0} e[n] + \underbrace{(-K_p + \tfrac{K_i T}{2})}_{b_1} e[n-1] + u[n-1] \]

where \( e \) is the error input and \( u \) is the control output. The feedback coefficient \( a_0 = -1 \) implements the accumulator (integrator).

Template Parameters
TSignal type (e.g., float, QuadDirectValues<float>).
Note
Anti-windup is implemented in BrushlessController::feedback() via output clamping and integrator back-calculation through set_output_state().
