Detailed Description

Two-phase brushed DC motor H-bridge driver.

Controls two PWM pins (high and low side) and a single enable pin. Voltage commands are converted to PWM duty cycles using the same volts_to_PWM() algorithm as BrushlessDriver.

Note
This class is partially implemented (no configure_center_aligned() support). It is retained for future use with brushed actuators.
