Detailed Description

Math utility constants and functions for FOC computations.

Provides compile-time constants for commonly used irrational numbers in Clarke/Park transform arithmetic, a precision-safe angle normaliser, and a paired sincos function that normalises its input before calling the floating-point trig library.

◆ normalize_angle()

template<typename T >
T normalize_angle ( T  radians)

Wraps an angle in radians to the half-open interval (−π, π].

Uses the identity:

\[ \theta_{\text{norm}} = \text{fmod}(\theta + \pi,\; 2\pi) - \pi \]

This is equivalent to iteratively adding or subtracting 2π until the result is in (−π, π], but executes in O(1) time using fmod.

Template Parameters
TFloating-point type.
Parameters
radiansInput angle in radians (any range).
Returns
Equivalent angle in (−π, π].
Note
Values exactly equal to −π may map to either −π or +π depending on floating-point rounding; for FOC applications this boundary is not critical.

◆ nu_sincos()

std::pair< float, float > nu_sincos ( float  radians)
inline

Computes sine and cosine together in a single call.

Normalises the input to (−π, π] before calling sinf / cosf, which improves floating-point accuracy for inputs far from zero (large multiturn accumulated angles).

Parameters
radiansInput angle in radians.
Returns
std::pair<float, float>{sin(radians), cos(radians)}.
Note
The normalisation adds one fmod call but is negligible compared to the trig functions themselves. On Cortex-M7, sinf / cosf use the hardware FPU and are approximately 20 cycles each.
