Detailed Description

Multi-turn angle tracking struct and abstract absolute encoder interface.

Provides:

  • Angle — tracks shaft position across multiple revolutions using a zero-crossing detection algorithm on successive raw encoder reads.
  • AbsoluteEncoder — abstract base class for absolute position sensors. Concrete implementations (e.g., SPIEncoder) override read().
